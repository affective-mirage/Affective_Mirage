# Affective Mirage Project Page

This repository hosts the project page for the WACV 2027 submission:

**Affective Mirage? Diagnosing Visual Grounding in Emotion Recognition with Vision Language Models**

The page is designed for GitHub Pages at:

https://affective-mirage.github.io/Affective_Mirage/

## Local preview

Run a static server from this directory:

```bash
python -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000/
```

## Main files

- `index.html`: page content.
- `static/css/index.css`: page-specific styling.
- `static/js/index.js`: copy-BibTeX and scroll-to-top interactions.
- `static/images/`: figures exported from `wacv2027_paper_submitted/figures/`.
- `static/pdfs/AffectMirage_paper.pdf`: paper PDF.
- `static/pdfs/AffectMirage_supplementary_material.pdf`: supplementary material PDF.
